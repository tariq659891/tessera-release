# Tessera

Desktop release artifacts for Tessera. Source code is private.

## Install

Download the latest release for your platform:
- macOS (Apple Silicon): `Tessera-x.y.z-arm64.dmg`
- macOS (Intel): `Tessera-x.y.z.dmg`
- Windows: `Tessera-Setup-x.y.z.exe`
- Linux: `Tessera-x.y.z.AppImage`

On first launch macOS may show "unidentified developer" — right-click the app → Open → Open.

The app auto-updates from this repository on subsequent launches.
